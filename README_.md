# 🎬 Amazon Prime Video Dashboard | Tableau

> **"Transforming streaming data into powerful visual insights!"**

An interactive Tableau dashboard built on Amazon Prime Video data, enabling users to explore and analyze over **9,000+ movies & TV shows** by genre, ratings, release year, and more — driving smarter, data-driven decisions.

---

## 📌 Features
✔ **Interactive Filters** – Explore content by genre, type, rating & release year
✔ **Radial Bar Chart** – Unique visualization for content distribution
✔ **Trend Analysis** – Discover how Prime Video's library has grown over time
✔ **Genre Insights** – Identify the most dominant content categories
✔ **Rating Breakdown** – Understand audience rating distributions at a glance

## 🗂️ Dataset Overview

| File | Description |
|------|-------------|
| `amazon_prime_titles.csv` | Core dataset with 9,000+ titles, genres, ratings & release years |
| `Amazon Prime Viz.twb` | Tableau workbook with all visualizations |
| `Radial Bar chart values.txt` | Custom values used for the radial bar chart |
